# 數學互動教室

以繁體中文編寫的階梯式數學教學動畫，可在瀏覽器直接使用，亦可下載 HTML 離線開啟。

**[開啟教學入口](https://fangchiwei-1104.github.io/math-geometry-animations/)**

| 單元 | 內容 | 線上使用 | 教學指南 |
|---|---|---|---|
| 空間座標系 | 14章、57步驟、14道檢核；座標、投影、距離公式、經緯度與球面距離 | [開始學習](https://fangchiwei-1104.github.io/math-geometry-animations/spatial-coordinates-lessons.html) | [指南與答案](spatial-guide.md) |
| 圓錐曲線 | 12章、45步驟、12道檢核；圓錐面、四種截痕、幾何計算與燈光應用 | [開始學習](https://fangchiwei-1104.github.io/math-geometry-animations/conic-lessons.html) | [指南與答案](conic-guide.md) |

## 使用

- 選擇章節，按「播放本章」或使用上一步／下一步逐步授課。
- 支援暫停、重播、投影模式及隨堂檢核。
- 空間座標系支援拖曳旋轉立體圖與投影／經緯度實驗室。
- 圓錐曲線支援切面角度調整與截痕比較。
- 語音使用瀏覽器／作業系統的中文語音；離線可用性取決於已安裝的聲音。完整字幕與公式始終可讀。
- 各 HTML 檔案無外部程式庫依賴，不需建置或安裝套件。

## 檔案

- `index.html`：共用入口。
- `spatial-coordinates-lessons.html`：空間座標系。
- `conic-lessons.html`：圓錐曲線。
- `spatial-guide.md`、`conic-guide.md`：授課節奏、操作方式及答案對照。
